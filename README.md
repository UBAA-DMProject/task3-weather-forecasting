# 气象时间序列 CO₂ 预测

北航《数据挖掘导论》2026 课程大作业任务三。使用过去两小时、每隔 10 分钟采集的全部 21 个指标，预测下一时间点的 `CO2 (ppm)`。

**当前状态：已完成 3.0 问题定义和 3.1 数据预处理与划分，并在本地真实数据上验证。3.2 模型训练和 3.3 预测评价尚未实现。**

本地报告和实验方案保存在 `docs/`，不纳入版本管理或仓库分发；数据处理及运行说明见下文。正式作业要求见 [作业说明](../course-project/docs/作业说明_2026.pdf) 第 4 页；相邻目录链接依赖当前工作区布局。

## 数据处理与划分

将课程原始文件放在 `dataset/weather.csv`，不修改或向原始数据目录写入产物。入口严格检查 `date` 和全部 21 个数值字段的名称及顺序。

- 完全相同的重复时间记录保留首次，保存原始零起始行索引及去重映射；同时间指标冲突、时间倒退、时间解析失败或字段错误时报错，禁止静默排序或取均值。
- 空白、不可转换数值、非有限数及 `-9999` 均标为无效。保留无效观测在时间轴上的位置，不填补、不插入缺失时刻。
- 输入为目标之前的 12 条记录，包含历史 CO₂；这 12 条输入和 1 条目标必须连续间隔 10 分钟。全部输入指标须有效，目标只要求 CO₂ 有效。
- 先按去重后的行数确定 70%／15%／15% 时间边界，再按目标归属划分有效窗口，不按过滤后样本数调整边界。验证／测试可以使用前一时间段末尾的历史观测。
- `StandardScaler` 仅在训练时间段内全部 21 维均有效的去重原始行上拟合，每行计入一次。只缩放输入，标签和保存的最后一次原始 CO₂ 均为 ppm。

评价场景为逐时刻单步预测，可以使用同一评价段中此前已到达的真实观测；不属于从测试起点递归预测整个时段。

## 环境与运行

已验证环境为 Python 3.12.3、NumPy 2.5.4、pandas 3.1.0、scikit-learn 1.9.1、joblib 1.6.0；完整依赖版本见 `requirements.txt`。在任务根目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest -v test_prepare_data
.venv/bin/python prepare_data.py --output-dir results/prepare_3_1
```

上述安装、测试和预处理命令均已执行成功。示例输出目录已有本次产物，再运行时须指定一个新目录。省略 `--output-dir` 时自动创建脚本目录下的 `results/prepare_<UTC时间戳>/`；省略 `--input` 时读取脚本目录下的 `dataset/weather.csv`。显式相对路径按当前工作目录解析。

入口支持 `--input` 和 `--output-dir`。输出目录已存在时拒绝覆盖；输出不得位于本项目 `dataset/` 或指定输入文件所在目录内部。运行目录创建后发生错误，会保存含阶段、原始行索引等详情的 `failure.json`，命令返回非零退出码。

## 输出与后续接口

完整产物位于独立实验目录，数据、虚拟环境、`results/` 和本地文档 `docs/` 由 `.gitignore` 忽略；代码、README 和 AGENTS.md 保持可版本管理。

| 产物 | 内容 |
| --- | --- |

| `scaler_fit_rows.csv`、`scaler_stats.json` | 缩放器拟合行、各特征均值、总体方差、缩放因子及常量列 |

| `verification.json` | 本次另行逐条对照原始 CSV 的独立核验记录；由实现验收时生成 |
| `failure.json` | 仅失败时生成，记录阶段、错误详情与调用栈；失败目录不直接重用 |

`dataset.npz` 的键约定如下，其中 `<split>` 为 `train`、`val` 或 `test`，`M` 为对应有效窗口数：

| 键 | 形状／类型 | 含义 |
| --- | --- | --- |
| `X_<split>` | `(M, 12, 21)`，float64 | 标准化输入，时间从早到晚，特征按 CSV 约定顺序 |
| `y_<split>` | `(M,)`，float64 | 未缩放的目标 CO₂，ppm |
| `last_co2_<split>` | `(M,)`，float64 | 最后一次原始 CO₂，供后续持续值基线使用 |
| `target_original_rows_<split>` | `(M,)`，int64 | 原始零起始行索引，不含表头 |
| `target_timestamps_<split>` | `(M,)`，datetime64[ns] | 与窗口及标签逐条对应的目标时间 |
| `feature_names`、`window_length` | Unicode 数组、整数标量 | 固定特征顺序和窗口长度 12 |

审计文件中的 `position` 表示去重后序列的零起始位置，`original_row` 表示原 CSV 的零起始行索引。`window_indices.csv` 包含开头历史不足的 12 个位置，缺少的历史索引留空；各原因次数不能相加作为排除总数。检查文件同时给出全部目标位置与完整候选窗口两种统计口径。
